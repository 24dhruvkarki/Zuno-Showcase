# Zuno

**Get paid. Without the chasing.**

Zuno is an invoicing and automated payment-reminder platform by Arakis, designed for freelancers, contractors, and small businesses. We’re building a simpler way to manage invoices, track payments, and follow up with clients.

## What Zuno Does

* **Invoice Management** — Create and organize invoices.
* **Payment Reminders** — Help businesses follow up on overdue payments.
* **Customer Management** — Keep customer and invoice records organized.
* **Business Settings** — Configure business details and payment preferences.

## Built With

* React
* TypeScript
* Vite
* Tailwind CSS
* Convex

## Project Status

🚧 Currently in development.
